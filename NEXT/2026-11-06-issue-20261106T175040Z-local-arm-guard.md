title: Guard the generated local gate re-arm caller so it yields to the organization arm (F-1R, #1905)
---
The caller that `scripts/gen-gate-rearm-caller.sh` generates now runs a read-only `guard` job before its `rearm` job, and `rearm` runs only when the guard keeps the local arm. On a `pull_request_target` opened, reopened, or synchronize event the guard reads the base ref's effective rules and yields only when a well-typed response carries a `workflows` rule naming `.github/workflows/gate-rearm.yml` from the organization `.github` repository (id 1269388380). Then the organization's required arm arms the head, and a skipped local `rearm` never enters the `ai-review-arm-<PR>` group, so it can no longer displace the pending required run. A read error, a response it cannot read, ambiguity, or absence keeps the local arm, which is the behavior before this change; the label and lifecycle `workflow_call` path is unchanged. The guard is never admission evidence: Gate W (ADR 0255) remains the sole fail-closed check of the required run. Adopters receive the guard only when their caller is regenerated, which waits on the live canaries ARB-G1-2026-11-06 requires (#1905).

The guard's decision logic is `scripts/local-arm-guard.sh`, which the generator embeds byte for byte. `scripts/ci-gate/local-arm-guard.test.py` exercises it against a stubbed `gh`, and `scripts/ci-gate/gate-rearm-caller-contract.test.sh` pins the `guard`/`needs`/`if` shape, the helper bytes, and the absence of concurrency at the workflow and job level. Every assertion was proven by a mutation.

The arm's runner-acquisition watchdog no longer tells a stalled caller head run to re-run unconditionally. It now advises a new head, and a re-run only where the base ref requires no organization arm, because a re-run there joins the arm's group and can displace the pending required run. This matches the runbook's never-rerun rule and ADR 0255 §6 as amended on 2026-11-06.

ADR 0255 carries a dated 2026-11-06 amendment recording F-1R under ARB-G1-2026-11-06. It reconciles the rejected "local caller that skips" alternative and the §4 and §6 advice, and keeps F-2/F-7 and F-6 recorded as residual risk. `docs/arm-recovery-runbook.md` now covers the one new Gate C shape. When a family run is displaced and a guard-skipped local run follows it, ADR 0226 does not set the displaced run aside, and the assertion exits 5. The recovery is to re-deliver the displaced event.
