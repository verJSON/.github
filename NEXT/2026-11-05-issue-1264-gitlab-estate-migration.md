title: Propose migrating the repository estate to GitLab CE behind a verified one-way mirror
---
Proposes ADR 0258, which moves the verJSON repository estate onto the self-hosted GitLab
CE in waves while GitHub stays authoritative. It adds a wave 0 rehearsal plan for three
low-risk repositories. Nothing has been executed, and no Git authority switch is
decided.

**Mirror.** GitLab CE has no pull mirroring and no CI/CD for external repositories; both
are Premium. So a sync worker fetches from GitHub and pushes into GitLab, and GitLab
never holds a GitHub credential.

- Reading GitHub uses a read-only GitHub App installed only on mirrored repositories.
- Writing GitLab uses one write deploy key per project, created by a non-administrator
  group service account through a one-day token held only in memory.
- The instance must run GitLab 18.11 or later: deploy keys in
  protected-branch and protected-tag rules are Free only from 18.10, and service
  accounts only from 18.11. The rehearsal preflight refuses an older instance.
- Tags never move. The default branch only fast-forwards. `refs/pull/*` is never
  mirrored.
- The worker extends the canonical `verjson-ci` mirror kit. It is not a new script.

**Waves.**

- Wave 0, the rehearsal: `agile-ai-manifesto`, `demo-repository` and
  `required-reviewers-rehearsal`.
- Wave 1: low-risk repositories.
- Wave 2: repositories with packages, releases, environments or secrets.
- Wave 3: control-plane repositories.

Each promotion needs owner approval.

**What migrates.** Refs and history migrate, and are verified by comparing ref lists and
object sets. Issues, pull requests, packages, releases, secrets and integrations stay on
GitHub. GitLab CI callers will be generated by `verjson-ci`, never written by hand. No CI
runs on the Netcup runners before verjson-git-runners#208's isolation evidence is
accepted, with one owner-approved exception: wave 0's CI leg may run plain,
credential-free test jobs on a dedicated rehearsal runner once its admission evidence is
accepted (ADR 0258 §5). Image, candidate and OCI build jobs still need the full #208
evidence. New projects fall into ADR 0256's backup scope.

**Rehearsal plan.** It holds placeholder-safe commands for each step: preflight, group
and project creation, protections, sync, verification, negative tests, the CI
comparison, teardown and the receipt. Every write step is marked as needing an
owner-approved rehearsal.

Part of #1264.
